# Coronation Hotel Hoima

A modern static hotel website template tailored for Coronation Hotel Hoima.

## Deployment on Vercel

1. Push this project to GitHub.
2. Open Vercel and import the repository.
3. Use the project root as the root directory.
4. Vercel will serve the static files automatically.

## Project files

- index.html — homepage
- service.html — services page
- contact.html — contact page
- css/ — stylesheets
- js/ — scripts
- img/ — images
- lib/ — third-party assets
